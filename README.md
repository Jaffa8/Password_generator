# Password Generator Web App

A secure, responsive web-based password generator that creates strong, customizable passwords. This app was converted from a React Native application to a web application while maintaining all original features and styling.

![Password Generator](https://github.com/user-attachments/assets/34770a64-e730-4a63-ae3a-88fa0801d453)

## Features

- ✅ **Strong Password Generation**: Create passwords with customizable length (4-20 characters)
- ✅ **Character Options**: Include/exclude uppercase, lowercase, numbers, and symbols
- ✅ **Copy to Clipboard**: One-click copy functionality with visual feedback
- ✅ **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- ✅ **Form Validation**: Built-in validation using Formik and Yup
- ✅ **Keyboard Shortcuts**: Press Escape to reset, Enter to generate
- ✅ **Accessibility**: Full keyboard navigation and screen reader support
- ✅ **PWA Ready**: Can be installed as a Progressive Web App on mobile devices
- ✅ **Beautiful UI**: Maintains the same visual design as the original React Native version

## Quick Start

```bash
npm install
npm start
# Open http://localhost:3000
```

## Deployment Ready

```bash
npm run build
# Deploy build/ folder to any static hosting service
```

Perfect for deployment on Vercel, Netlify, GitHub Pages, or any static hosting platform.
